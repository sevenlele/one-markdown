# Changelog

## v0.1.0 (Initial Release)

### Features
- Single-file Markdown workflow — no Vault, no project, just open `.md` and write
- Live preview with syntax-highlighted code blocks (pulldown-cmark + syntect)
- YAML frontmatter support (title, tags, date, description, author)
- Image paste — auto-embed as base64 data URI or save to `.assets/` directory
- AI assistant (Ctrl+L) — explain, summarize, translate, rewrite, context bundle
- OpenAI-compatible API integration (works with any OpenAI-format endpoint)
- Export to standalone HTML with dark theme
- Resizable split-pane editor/preview
- Keyboard shortcuts (Ctrl+B/I/K/E/L/N/O/S)
- Recent files tracking
- Cross-platform: Windows, macOS, Linux
- ~5MB install size, <100ms cold start
